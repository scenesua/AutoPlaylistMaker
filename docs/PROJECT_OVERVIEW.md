# 프로젝트 개요

## 목적과 사용자

Auto Playlist Maker는 여러 음원을 분석·분배·편집하고 이미지·텍스트·오디오 비주얼라이저를 결합해 장시간 플레이리스트 영상을 생성하는 데스크톱 애플리케이션이다. 주요 사용자는 YouTube 등 영상 플랫폼용 믹스 영상을 반복 제작하는 음악 채널 운영자와 개인 제작자다.

## 핵심 기능

1. 음원·이미지·영상 가져오기와 프로젝트 백업
2. BPM, 키, 모드, Camelot, 에너지·파형 분석
3. 목표 길이 기반 자동 분배와 수동 그룹 편집
4. 파형 타임라인 트림, 순서·볼륨·페이드 조절과 미리듣기
5. 그룹별 이미지·영상 클립 구성
6. 배경·오버레이·텍스트·비주얼라이저·효과 디자인
7. 실제 렌더러 기반 미리보기와 두 곡 전환 구간 확인
8. 반복 횟수 또는 목표 시간 기반 전체 플레이리스트 반복
9. FFmpeg 기반 오디오 믹싱, 영상 인코딩, 취소·재시도
10. 프로젝트 전체 상태 저장·복원과 누락 미디어 재연결
11. 한국어 포함 11개 언어 UI

## 기술 스택과 실행 환경

- Python 3.12
- Tkinter 및 `tkinterdnd2`
- NumPy, SciPy, librosa, SoundFile, pydub
- Pillow, MoviePy, imageio, imageio-ffmpeg
- FFmpeg 외부 프로세스
- PyInstaller Windows one-dir/one-file 빌드
- GitHub Actions 태그 기반 Windows/macOS 릴리스 작업

Windows 11에서 1.3.0 폴더형 패키지를 직접 검증했다. GitHub Actions에서 Windows와 macOS 패키지 빌드 및 공개 릴리스를 확인했지만, 실제 macOS 장비의 `.app` 실행 smoke는 `ISSUE-BUILD-003`으로 남아 있다.

## 전체 작업 흐름

```text
프로젝트·음원 불러오기
→ 자동/수동 분배
→ 파형 기반 음원 편집
→ 이미지·영상 클립 구성
→ 디자인·효과·반복 설정과 미리보기
→ 렌더 설정·작업 큐·출력
```

## 현재 개발 단계

1.3.0은 `v1.3.0` 태그로 정식 릴리스됐다. 다음 작업 버전은 사용자가 지정한 1.3.1이며, 1.3.0 동작과 project format v4 호환성을 유지하면서 버그 개선과 최적화를 진행한다.

## 반드시 유지할 특성

- 마지막 곡이나 반복 구간을 잘라 목표 시간을 맞추지 않는다.
- 트림 핸들은 잡고 있는 동안만 움직이고 최소 길이와 음원 범위를 지킨다.
- 프로젝트를 이동해도 백업 미디어와 분석 캐시를 복원할 수 있어야 한다.
- 누락 파일 때문에 앱이 종료되지 않고 재연결 경로를 제공해야 한다.
- 미리보기와 출력은 동일한 해상도·FPS·레이아웃·렌더링 설정을 사용해야 한다.
- 언어 변경이 프로젝트 상태나 안정적인 선택 ID를 바꾸면 안 된다.
- 렌더 취소·앱 종료 후 FFmpeg 등 하위 프로세스가 남으면 안 된다.
- 현재 외부 저장 형식과 공개 모듈 함수는 명시적 마이그레이션 없이 제거하지 않는다.

세부 구현은 [`ARCHITECTURE.md`](ARCHITECTURE.md), 요구사항은 [`REQUIREMENTS.md`](REQUIREMENTS.md)를 참조한다.
