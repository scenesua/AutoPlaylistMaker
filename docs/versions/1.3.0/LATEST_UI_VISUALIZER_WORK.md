# 1.3.0 UI·비주얼라이저 최신 작업

## 구현

- Noto Sans KR 기반 타이포그래피와 공통 디자인 토큰 적용
- 밝은 모드 상단 내비게이션 및 Stage 4 잔여 고정 배경 수정
- 버튼·입력·체크·선택·비활성·스크롤·슬라이더 상태 개선
- 분석/프로젝트 로드 실제 진행 오버레이와 취소 경로
- 분석 파형 재사용 및 원본 파일 단위 캐시 무효화
- 타임라인 의미 색상과 클립 미리보기 리사이즈/비율 저장
- Alt+클릭 슬라이더 기본값 복원과 11개 언어 안내
- 비주얼라이저 트림 시간 동기화와 2곡별 정규화/스무딩 캐시 분리
- FFT·파형이 빠진 구형 캐시는 프로젝트 로드 중 해당 파일만 재분석

## 검증

- 전체 테스트: 56 passed
- locale: 0 errors / 0 warnings
- 변경 모듈 컴파일 통과
- 밝은/어두운 모드, 950×620 및 1200×750 직접 캡처 확인
- 실제 FFT 변화, 트림 시작점, 2곡 전환, 검은 화면 숨김 픽셀 테스트 통과
- 2초 MP4 실제 렌더 후 추출 프레임에서 비주얼라이저 확인
- 전체 Ruff는 기존 코드의 선행 위반 75건 때문에 통과하지 않으며 대규모 자동 정리는 하지 않음

## 조사 결론

Git 기록에서 확인 가능한 최신 릴리스는 v1.2.1이다. 현재 공통 렌더러 구조는 그 시점에도 존재하므로 특정 버전부터 고장났다고 단정할 근거는 없다. 코드에서 확인된 실제 결함은 트림 시작 시간을 FFT 조회에 더하지 않은 점, 파일명 기준 캐시 충돌, 구형 불완전 캐시를 정상 캐시처럼 받아 조용히 비주얼라이저를 생략한 점이다.
