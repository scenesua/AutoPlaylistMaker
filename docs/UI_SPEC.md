# UI/UX 기준

## 상태 구분

- **현재 유지**: 실제 코드에 연결됐고 회귀시키면 안 되는 동작
- **검증 필요**: 구현은 있으나 요구된 수동 전수 검사가 부족한 동작
- **폐기된 방식**: 다시 도입하지 않을 이전 방식

## 전체 구조 — 현재 유지

- 기본 창 1200×750, 최소 950×620.
- 상단 내비게이션에 이전/다음, 단계명, 6개 진행점, 프로젝트/dirty 상태, 테마 전환을 둔다.
- 작업 순서: 프로젝트 → 분배 → 음원 편집 → 클립 → 디자인/효과 → 렌더.
- 마지막 렌더 단계에서는 다음 버튼을 숨긴다.
- 다크/라이트 테마와 아랍어 RTL 내비게이션을 지원한다.
- 패키지에서는 첫 단계 외 UI를 처음 방문할 때 만든다.

## 공통 디자인 시스템 — 현재 유지

- `Noto Sans KR`을 Windows 기본 UI 서체로 사용해 한글·영문 혼용 가독성을 유지한다.
- 8px 기반 간격과 배경·작업 영역·패널의 3단계 표면을 사용한다.
- 주요 행동은 보라색, 위험 행동은 빨간 텍스트 또는 위험 상태, 일반 행동은 중립 표면으로 구분한다.
- 버튼은 기본·hover·focus·disabled 상태를, 입력창은 focus·disabled 상태를 명암과 테두리로 함께 표시한다.
- 입력창, 체크박스, 표, scrollbar, scale은 공통 ttk style을 사용한다.
- 화면 제목, 섹션 제목, 본문, 보조 설명의 크기·굵기·명암을 구분한다.
- Stage 4·5의 좌우 작업 패널은 낮은 대비 경계와 리사이즈 sash를 사용한다.

## 단계별 화면 — 현재 유지

### 프로젝트·분석

- 파일 drop/click 영역, 분석 결과 표, 목표 시간·허용 오차, 프로젝트 새로 만들기/열기/저장/재연결.
- 언어 팝업과 커피 아이콘 후원 링크를 첫 단계에 둔다.
- 누락 파일은 앱을 종료하지 않고 상태로 표시한다.

### 분배

- 자동 모드와 수동 모드를 분리한다.
- 수동 모드는 왼쪽 전체/미분배 곡, 오른쪽 그룹과 그룹 곡을 사용한다.
- 항목 사이 drop 위치는 어두운 공간과 가로 삽입선으로 표시한다.
- 최상단·최하단·빈 그룹·그룹 간 이동을 허용한다.
- 그룹이 없을 때 오른쪽 전체가 drop target이며 최초 이동 하나로 `Mix N` 그룹을 만든다.
- drag 취소·영역 이탈·release 후 indicator와 grab을 즉시 정리한다.

### 음원 편집

- 파형 타임라인, trim handle, playhead, horizontal scroll/zoom, undo/redo를 제공한다.
- handle 위에서는 수평 resize 의미의 cursor, 트랙 drag에서는 이동 cursor를 사용한다.
- handle을 누른 동안만 값이 바뀌며 release 후 hover는 값을 바꾸지 않는다.
- 기본 drag는 snap, Shift는 세밀, Alt는 극미세 조절이다.
- 현재 시간은 `분:초.밀리초`로 표시한다.
- 숫자 모달은 보조 정밀 입력으로 유지한다.

### 클립

- 그룹 탭, 이미지/영상 목록, 썸네일, 추가·삭제·상하 이동, 간격·random 설정을 제공한다.
- 썸네일 생성은 UI thread를 막지 않고 결과 queue로 전달한다.

### 디자인·효과

- 좌측은 preview와 scrubber, 우측은 독립 vertical scroll을 가진 효과·설정 inspector다.
- 새 프로젝트의 효과 목록은 비어 있으며 `+ 효과 추가` 메뉴에서 현재 구현된 효과만 골라 카드로 추가한다.
- 효과 선택 메뉴는 검색, 카테고리, 내부 스크롤, 방향키·Enter·Esc와 바깥 클릭 닫기를 지원한다.
- 추가된 효과 카드만 렌더 대상이며 카드 전체 또는 섹션 단위 기본값 복원을 제공한다.
- 배경/오버레이, visualizer, fade, 일반/커스텀 text, beat/CRT, 표시 시간, 반복, 해상도/FPS를 편집한다.
- 일반·커스텀 폰트는 동일한 검색형 팝업 컴포넌트를 사용한다.
- 반복 횟수/목표 시간과 예상 결과를 여기서 편집한다.
- 라이브 preview와 선택 가능한 두 곡 preview를 제공한다.
- 전역 오디오는 효과 목록과 분리된 고정 영역이며 음악·음량 정규화·환경음·고급 설정을 접기/펼치기로 구분한다.
- 실시간 L/R 미터는 최종 master, music bus, ambient bus 중 하나를 선택해 실제 preview stem을 표시한다.

### 렌더

- 좌측에 출력 해상도·FPS·codec·bitrate와 전역 오디오·반복 요약을 둔다.
- 반복 값은 읽기 전용 요약이며 “디자인/효과에서 편집”으로 이동한다.
- 우측에 그룹 queue, 시작/취소/실패 재시도, progress와 ETA를 둔다.

## 팝업과 내부 스크롤 — 현재 유지

- 언어 팝업은 11개 언어를 3열 그리드로 표시하고 top-level overlay와 grab을 사용하며 Esc/닫기/적용으로 정리한다.
- 폰트 팝업은 top-level overlay, 검색 input, 제한 높이 listbox와 내부 scrollbar를 사용한다.
- 폰트 목록 wheel은 목록에서 소비하고 부모 설정 패널로 전달하지 않는다.
- 바깥 클릭과 destroy 때 root binding과 debounce timer를 해제한다.
- Stage 4·5 설정 canvas는 자체 scrollbar를 사용한다.

## 선택·키보드·마우스 — 현재 유지

- 폰트: Down, Enter, Esc, 검색 자동 focus.
- 음원 편집: Ctrl+Z, Ctrl+Y, wheel scroll, Ctrl+wheel zoom, double-click 보조 trim 편집.
- DnD 중 텍스트 선택과 흔들림을 최소화하고 drag source를 구분한다.
- 다중 선택 이동은 표시 순서를 유지한다.
- 모든 modal/popup/drag는 화면 전환과 destroy에서 grab·listener·timer를 정리한다.

## 미리보기와 출력 — 현재 유지

- 출력 해상도 좌표를 기준으로 요소 위치·크기를 저장한다.
- `scale=min(previewWidth/outputWidth, previewHeight/outputHeight)`로 완성 프레임 전체를 축소한다.
- 종횡비가 다르면 letterbox/pillarbox를 허용한다.
- 해상도와 FPS는 디자인·렌더 단계가 동일한 live value를 사용한다.
- 배경 cover/contain, text/overlay/visualizer/effect는 `LiveFrameRenderer`를 공유한다.

## 오류·진행·비활성 상태 — 현재 유지

- 분석·미리보기·렌더 같은 긴 작업은 상태 문구와 progress를 표시한다.
- 렌더 중 시작 버튼을 비활성화하고 취소를 활성화한다.
- 삭제·취소 같은 위험 행동은 기본 상태에서 빨간 텍스트, hover에서 빨간 배경과 흰 텍스트로 표시한다.
- 추가 행동은 기본 상태에서 초록 텍스트, hover에서 초록 배경과 흰 텍스트로 표시한다.
- 실패 그룹은 queue에 오류를 표시하고 재시도를 허용한다.
- 저장 실패·FFmpeg 누락·잘못된 반복/해상도/LUFS 입력은 사용자에게 경고한다.
- dirty 상태와 종료 전 확인을 표시한다.

## 검증 필요

- 950×620, 일반 창, 최대화에서 모든 언어의 긴 문구 겹침.
- 네 해상도 미리보기/출력 시각 비교: ISSUE-TEST-001.
- 모든 visualizer 스타일의 낮은/높은 음량 움직임.
- 실제 GPU codec 선택·fallback UX.

## 시작 화면과 브랜드 — 현재 유지

- Windows 진입점은 240×180 투명 레이어드 창에 보라색 재생·목록 심볼만 cold start 5초 이내 표시한다.
- 첫 화면에는 사각 배경·텍스트·진행 표시를 두지 않고 그림자·그라데이션·halo도 넣지 않는다.
- Tk 준비 시 첫 화면을 440×300 로딩 스플래시로 교체한다. 로딩 화면은 짙은 남색 바탕, 앱 이름·버전, 현재 작업 문구와 진행 바를 표시한다.
- 로딩 스플래시는 실제 메인 창이 보이기 직전에 닫고, 메인 창 표시 뒤 중복 창이나 작업 표시줄 항목을 남기지 않는다.
- 창 아이콘과 스플래시는 동일한 심볼을 사용한다.

## 폐기된 방식

- 항상 펼쳐진 긴 폰트 Listbox.
- mouse release 후에도 trim point가 pointer를 따라가는 전역 drag 상태.
- 그룹이 없으면 사용자가 먼저 생성 버튼을 눌러야 하는 흐름.
- 목표 시간을 맞추기 위해 마지막 곡/반복을 자르는 방식.
- 디자인과 렌더 양쪽에 서로 다른 반복 설정 객체를 두는 방식.
- 미리보기용 요소 크기를 출력과 별도로 계산하는 방식.
- 번역된 표시 문구를 프로젝트 선택값으로 저장하는 방식.
